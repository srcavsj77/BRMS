# BRMS Domain Mock (in-memory)

Conteúdo: modelos de domínio, serviços imutáveis e um mock API mínimo em Express.

Para executar localmente:

1. Abra um terminal em `BRMS/domain`
2. Rode:

```bash
npm install
npm run dev
```

O servidor inicia por padrão em `http://localhost:3333` e expõe endpoints para `rules`, `documents`, `applications`, `audits` e `versions`.
