# PROMPT MASTER — Frontend Enterprise Prototype

Esqueleto frontend com layout enterprise, componentes principais e configs (TypeScript + Tailwind).

Passos para executar localmente:

1. Entrar na pasta do app:

```bash
cd apps/prompt-master-enterprise
```

2. Instalar dependências:

```bash
npm install
```

3. Rodar em desenvolvimento (porta 3002):

```bash
npm run dev
```

Observações:
- Este é um esqueleto inicial com componentes stub (Sidebar, Header, Dashboard, Wizard, Editor).
- Dependências adicionais (shadcn/ui, design tokens, integração IA, gráficos) devem ser instaladas conforme evolução.
